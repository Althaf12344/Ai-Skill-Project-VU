# 🎯 AI Skill Gap Classification using Decision Tree

## 📌 Project Overview

This project uses Machine Learning to classify the skill gap level of college students based on their academic performance, technical skills, communication ability, aptitude, projects, internships, and certifications.

A Decision Tree Classifier is trained to predict whether a student's skill gap is **High**, **Medium**, or **Low**, helping identify areas that require improvement.
